ZEHN ACADEMY — ALI TEACHER (БЕПУЛ ДЕМО)

ИШГА ТУШИРИШ:
1. Компьютерда Node.js ўрнатилган бўлсин.
2. Шу папкада терминал очинг.
3. Биринчи марта: npm install
4. Ишга тушириш: npm start
5. Браузерда http://localhost:3000 манзилини очинг.

ALI TEACHER ДЕМО РЕЖИМИ:
- API калити талаб қилинмайди.
- Чатда бир нечта асосий намунавий мавзуларга жавоб беради.
- Микрофон ва браузернинг овоз чиқариш имкониятлари интерфейсда қолдирилган.
- Бу тўлиқ генератив AI эмас; жавоблар олдиндан тайёрланган қоидалар асосида берилади.
- Интернетсиз ҳам локал сервер ишлаши мумкин; микрофон имконияти браузерга боғлиқ.

ЭСКИ OPENAI API КАЛИТИ:
Бу демо учун OPENAI_API_KEY керак эмас. Хавфсизлик учун .env файлидаги калитни ўчириб қўйишингиз мумкин. Калитни ҳеч кимга юборманг.

ТЎХТАТИШ:
Терминалда Ctrl + C босинг.
